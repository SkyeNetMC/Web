<div class="category-intro">
  <h2>Basic Machines</h2>
  <p>Basic Machines are superior blocks that are used to create better or faster results than vanilla Minecraft blocks (Furnace, Crafting Table, etc.). A basic machine can either be crafted or built as a multi-block structure.</p>
  <p>Multi-block structures are 2 or more blocks placed in an arrangement making one whole machine. Multi-block structures are the main tools needed to craft materials for items you unlock with the Slimefun guide.</p>
</div>

## Core Machines

<div class="item-card">
  <h3 class="item-title">Output Chest</h3>
  <div class="item-description">
    <p>The Output Chest is a Basic Machine that can be placed adjacent to a Basic Machine's Dispenser and will automatically pull materials crafted by the Basic Machine.</p>
    <div class="usage-instructions">
      <strong>Crafting:</strong> Can be crafted at the Enhanced Crafting Table.
    </div>
    <div class="special-note">
      <strong>Function:</strong> Essential for automating machine output collection. Place next to any machine's dispenser to automatically collect crafted items.
    </div>
  </div>
</div>

<div class="item-card">
  <h3 class="item-title">Enhanced Crafting Table</h3>
  <div class="item-description">
    <p>The Enhanced Crafting Table is a multi-block structure used to craft most of the basic components needed for Slimefun items.</p>
    <div class="usage-instructions">
      <strong>Construction:</strong> Multi-block structure requiring specific block arrangement
    </div>
    <div class="special-note">
      <strong>Importance:</strong> This is a fundamental machine required for crafting many other Slimefun components including Output Chests, Automatic Ignition Chambers, and Composters.
    </div>
    <div class="ingredient-list">
      <h4>Can Craft:</h4>
      <ul>
        <li>Output Chest</li>
        <li>Automatic Ignition Chamber</li>
        <li>Composter</li>
        <li>Basic circuit components</li>
        <li>Tool upgrades</li>
      </ul>
    </div>
  </div>
</div>

## Processing Machines

<div class="item-card">
  <h3 class="item-title">Grind Stone</h3>
  <div class="item-description">
    <p>The Grind Stone is a multi-block structure that grinds items into different items, providing essential material transformation capabilities.</p>
    <div class="usage-instructions">
      <strong>Function:</strong> Converts various materials into ground/powdered forms
    </div>
    <div class="ingredient-list">
      <h4>Common Conversions:</h4>
      <ul>
        <li>Cobblestone → Gravel</li>
        <li>Gravel → Sand</li>
        <li>Sand → Dust</li>
        <li>Various ores → Dusts</li>
      </ul>
    </div>
  </div>
</div>

<div class="item-card">
  <h3 class="item-title">Ore Crusher</h3>
  <div class="item-description">
    <p>The Ore Crusher is a multi-block structure used to create Iron/Gold Dust from their Ore or Sulfate from Netherrack.</p>
    <div class="usage-instructions">
      <strong>Primary Function:</strong> Converts ores into dust form for further processing in the Smeltery.
    </div>
    <div class="ingredient-list">
      <h4>Processing Capabilities:</h4>
      <ul>
        <li>Iron Ore → Iron Dust</li>
        <li>Gold Ore → Gold Dust</li>
        <li>Netherrack → Sulfate</li>
        <li>Other metal ores → Corresponding dusts</li>
      </ul>
    </div>
    <div class="special-note">
      <strong>Efficiency:</strong> Essential first step in advanced metallurgy - dust can be smelted more efficiently than raw ore.
    </div>
  </div>
</div>

<div class="item-card">
  <h3 class="item-title">Ore Washer</h3>
  <div class="item-description">
    <p>The Ore Washer is a multi-block structure that washes Sifted Ore to filter and purify ores.</p>
    <div class="usage-instructions">
      <strong>Process:</strong> Input Sifted Ore to get purified ore dusts with higher yields
    </div>
    <div class="ingredient-list">
      <h4>Creates Various Ore Dusts:</h4>
      <ul>
        <li>Aluminum Dust</li>
        <li>Copper Dust</li>
        <li>Tin Dust</li>
        <li>Zinc Dust</li>
        <li>Magnesium Dust</li>
        <li>Lead Dust</li>
      </ul>
    </div>
    <div class="special-note">
      <strong>Requirement:</strong> Requires Sifted Ore from the Automated Panning Machine
    </div>
  </div>
</div>

<div class="item-card">
  <h3 class="item-title">Automated Panning Machine</h3>
  <div class="item-description">
    <p>The Automated Panning Machine is a multi-block structure that converts Gravel into Flint, Clay and Sifted Ore.</p>
    <div class="usage-instructions">
      <strong>Usage:</strong> Right click the trapdoor with Gravel in your hand to start the panning process.
    </div>
    <div class="ingredient-list">
      <h4>Output Products:</h4>
      <ul>
        <li><strong>Flint:</strong> Used in various recipes</li>
        <li><strong>Clay:</strong> Building and crafting material</li>
        <li><strong>Sifted Ore:</strong> Input for Ore Washer to get pure ore dusts</li>
      </ul>
    </div>
    <div class="special-note">
      <strong>Chain Process:</strong> Gravel → Automated Panning Machine → Sifted Ore → Ore Washer → Pure Ore Dusts
    </div>
  </div>
</div>

## Smelting and Compression

<div class="item-card">
  <h3 class="item-title">Smeltery</h3>
  <div class="item-description">
    <p>The Smeltery is a multi-block structure that converts Dusts into Ingots and is used to create Alloys and some Synthetic Gems.</p>
    <div class="usage-instructions">
      <strong>Primary Functions:</strong>
      <ul>
        <li>Convert dusts into ingots</li>
        <li>Create complex alloys</li>
        <li>Produce synthetic gems</li>
      </ul>
    </div>
    <div class="ingredient-list">
      <h4>Can Create:</h4>
      <ul>
        <li><strong>Basic Metals:</strong> Copper, Tin, Zinc, Lead, Silver, Aluminum ingots</li>
        <li><strong>Alloys:</strong> Steel, Bronze, Brass, Damascus Steel, Reinforced Alloy</li>
        <li><strong>Synthetic Gems:</strong> Synthetic Diamond, Emerald, Sapphire</li>
        <li><strong>Special Materials:</strong> Carbonado, various carat gold</li>
      </ul>
    </div>
    <div class="special-note">
      <strong>Important:</strong> The fire under the Smeltery has a chance to be consumed when being used. Use an Automatic Ignition Chamber to prevent this.
    </div>
  </div>
</div>

<div class="item-card">
  <h3 class="item-title">Automatic Ignition Chamber</h3>
  <div class="item-description">
    <p>Prevents the Smeltery from using up fire. Essential for continuous smeltery operation.</p>
    <div class="usage-instructions">
      <strong>Setup:</strong> Fill with Flint and Steel and place adjacent to Smeltery's dispenser.
    </div>
    <div class="usage-instructions">
      <strong>Crafting:</strong> Can be crafted at the Enhanced Crafting Table.
    </div>
    <div class="special-note">
      <strong>Benefit:</strong> Eliminates the need to constantly replace fire under the Smeltery, enabling automated operation.
    </div>
  </div>
</div>

<div class="item-card">
  <h3 class="item-title">Compressor</h3>
  <div class="item-description">
    <p>The Compressor is a multi-block structure that compresses items into more compact or advanced forms.</p>
    <div class="usage-instructions">
      <strong>Primary Use:</strong> Create Carbon and various compressed materials
    </div>
    <div class="ingredient-list">
      <h4>Compression Products:</h4>
      <ul>
        <li><strong>Carbon:</strong> From coal or other carbon sources</li>
        <li><strong>Compressed Carbon:</strong> Intermediate material</li>
        <li><strong>Stone Chunks:</strong> Compressed stone materials</li>
        <li><strong>Various compressed resources</strong></li>
      </ul>
    </div>
  </div>
</div>

<div class="item-card">
  <h3 class="item-title">Pressure Chamber</h3>
  <div class="item-description">
    <p>The Pressure Chamber is a multi-block structure that compresses items even further than the regular Compressor.</p>
    <div class="usage-instructions">
      <strong>Advanced Compression:</strong> Creates materials impossible to make with basic compression
    </div>
    <div class="ingredient-list">
      <h4>Exclusive Products:</h4>
      <ul>
        <li><strong>Synthetic Diamond:</strong> High-pressure compressed carbon</li>
        <li><strong>Carbon Chunks:</strong> Ultra-compressed carbon</li>
        <li><strong>Raw Carbonado:</strong> Extremely rare compressed material</li>
        <li><strong>Advanced alloys</strong> requiring extreme pressure</li>
      </ul>
    </div>
    <div class="special-note">
      <strong>Requirement:</strong> Needs materials pre-processed in the regular Compressor
    </div>
  </div>
</div>

## Specialized Machines

<div class="item-card">
  <h3 class="item-title">Magic Workbench</h3>
  <div class="item-description">
    <p>The Magic Workbench is a multi-block structure used for Magical Items and Components.</p>
    <div class="usage-instructions">
      <strong>Magical Crafting:</strong> Essential for creating enchanted and magical items
    </div>
    <div class="ingredient-list">
      <h4>Can Create:</h4>
      <ul>
        <li><strong>Talismans:</strong> All talisman types and tiers</li>
        <li><strong>Magical Components:</strong> Magical Lumps, Ender Lumps</li>
        <li><strong>Enchanted Items:</strong> Magical staffs, enchanted tools</li>
        <li><strong>Mystical Materials:</strong> Essence of Afterlife, Necrotic Skulls</li>
      </ul>
    </div>
    <div class="special-note">
      <strong>Required:</strong> Also required in order to craft Talismans. No magical items can be created without this workbench.
    </div>
  </div>
</div>

<div class="item-card">
  <h3 class="item-title">Armor Forge</h3>
  <div class="item-description">
    <p>The Armor Forge is a multi-block structure used to create all armor sets available in Slimefun.</p>
    <div class="usage-instructions">
      <strong>Armor Creation:</strong> Crafts both regular and magical armor sets
    </div>
    <div class="ingredient-list">
      <h4>Can Create:</h4>
      <ul>
        <li><strong>Regular Armor:</strong> Damascus, Reinforced, Cactus, Chain, Hazmat, Gilded</li>
        <li><strong>Special Armor:</strong> 12 Carat Gold, Heavy Metal</li>
        <li><strong>Magical Armor:</strong> Ender, Slime, Steel Slime, Glowstone</li>
        <li><strong>Specialized Items:</strong> Boots of the Stomper</li>
      </ul>
    </div>
    <div class="special-note">
      <strong>Exclusive:</strong> All Slimefun armor must be crafted here - cannot be made in regular crafting table
    </div>
  </div>
</div>

<div class="item-card">
  <h3 class="item-title">Table Saw</h3>
  <div class="item-description">
    <p>The Table Saw is a multi-block structure that converts logs into planks more efficiently than vanilla crafting.</p>
    <div class="usage-instructions">
      <strong>Efficiency Boost:</strong> 1 log → 8 planks (double vanilla efficiency)
    </div>
    <div class="special-note">
      <strong>Comparison:</strong> Vanilla crafting: 1 log → 4 planks | Table Saw: 1 log → 8 planks
    </div>
    <div class="ingredient-list">
      <h4>Supported Wood Types:</h4>
      <ul>
        <li>Oak, Birch, Spruce, Jungle</li>
        <li>Acacia, Dark Oak</li>
        <li>Crimson, Warped (Nether woods)</li>
      </ul>
    </div>
  </div>
</div>

<div class="item-card">
  <h3 class="item-title">Composter</h3>
  <div class="item-description">
    <p>Converts various organic materials over time into useful byproducts.</p>
    <div class="usage-instructions">
      <strong>Crafting:</strong> Can be crafted at the Enhanced Crafting Table.
    </div>
    <div class="ingredient-list">
      <h4>Input Materials:</h4>
      <ul>
        <li>Food scraps and organic waste</li>
        <li>Plant materials</li>
        <li>Rotten flesh and organic drops</li>
      </ul>
    </div>
    <div class="ingredient-list">
      <h4>Output Products:</h4>
      <ul>
        <li>Fertilizer for enhanced crop growth</li>
        <li>Organic compounds for recipes</li>
        <li>Biomass for fuel</li>
      </ul>
    </div>
  </div>
</div>

## Mining and Extraction

<div class="item-card">
  <h3 class="item-title">Industrial Miner</h3>
  <div class="item-description">
    <p>The Industrial Miner is a multi-block structure that automatically digs out ores from the ground below it.</p>
    <div class="special-note">
      <strong>Coverage:</strong> 7×7 block radius mining area
    </div>
    <div class="usage-instructions">
      <strong>Operation:</strong> Automatically mines ores in a large area below the machine
    </div>
    <div class="ingredient-list">
      <h4>Features:</h4>
      <ul>
        <li>Automatic ore detection and mining</li>
        <li>Large coverage area</li>
        <li>Continuous operation</li>
        <li>Output chest compatible</li>
      </ul>
    </div>
  </div>
</div>

<div class="item-card">
  <h3 class="item-title">Advanced Industrial Miner</h3>
  <div class="item-description">
    <p>The Advanced Industrial Miner is an upgraded version that digs out ores from an even larger area.</p>
    <div class="special-note">
      <strong>Coverage:</strong> 11×11 block radius mining area (upgraded from 7×7)
    </div>
    <div class="usage-instructions">
      <strong>Enhanced Features:</strong> All features of Industrial Miner but with significantly larger coverage
    </div>
    <div class="ingredient-list">
      <h4>Improvements over Industrial Miner:</h4>
      <ul>
        <li>57% larger mining area (121 vs 49 blocks)</li>
        <li>Faster mining speed</li>
        <li>Better ore detection</li>
        <li>Higher energy efficiency</li>
      </ul>
    </div>
  </div>
</div>

## Utility Machines

<div class="item-card">
  <h3 class="item-title">Crucible</h3>
  <div class="item-description">
    <p>A magical machine that converts Cobblestone into Lava through mystical processes.</p>
    <div class="usage-instructions">
      <strong>Usage:</strong> Right click the Dispenser with Cobblestone in your hand
    </div>
    <div class="special-note">
      <strong>Function:</strong> Cobblestone → Lava conversion for infinite lava source
    </div>
    <div class="ingredient-list">
      <h4>Applications:</h4>
      <ul>
        <li>Infinite lava source for fuel</li>
        <li>Obsidian production</li>
        <li>Smeltery fuel supply</li>
        <li>Industrial heating applications</li>
      </ul>
    </div>
  </div>
</div>

<div class="item-card">
  <h3 class="item-title">Juicer</h3>
  <div class="item-description">
    <p>Used to create various nutritious juices from fruits and vegetables.</p>
    <div class="usage-instructions">
      <strong>Usage:</strong> Put in the ingredient and right click the fence to activate.
    </div>
    <div class="ingredient-list">
      <h4>Can Create:</h4>
      <ul>
        <li><strong>Apple Juice:</strong> From apples - fills 5 hunger bars</li>
        <li><strong>Melon Juice:</strong> From melons - fills 5 hunger bars</li>
        <li><strong>Carrot Juice:</strong> From carrots - fills 5 hunger bars</li>
        <li><strong>Golden Apple Juice:</strong> From golden apples - provides Absorption effect</li>
      </ul>
    </div>
    <div class="special-note">
      <strong>Nutrition:</strong> All basic juices fill 5 hunger bars, much more efficient than raw ingredients
    </div>
  </div>
</div>

## Enhanced Furnaces

<div class="item-card">
  <h3 class="item-title">Enhanced Furnaces</h3>
  <div class="item-description">
    <p>Enhanced furnaces come with various tiers. Each tier increases the speed, the fuel efficiency and the fortune which is applied on smelted Items.</p>
    <div class="ingredient-list">
      <h4>Enhanced Furnace Tiers:</h4>
      <ul>
        <li><strong>Enhanced Furnace I:</strong> Basic improvements over vanilla furnace</li>
        <li><strong>Enhanced Furnace II:</strong> Better speed and efficiency</li>
        <li><strong>Enhanced Furnace III:</strong> Moderate speed increase</li>
        <li><strong>Enhanced Furnace IV:</strong> Fast smelting with Fortune I</li>
        <li><strong>Enhanced Furnace V:</strong> Very fast with Fortune II</li>
        <li><strong>Enhanced Furnace VI:</strong> Extremely fast with Fortune III</li>
        <li><strong>Enhanced Furnace VII:</strong> Near-instant smelting</li>
        <li><strong>Enhanced Furnace VIII:</strong> Super-fast automated smelting</li>
        <li><strong>Enhanced Furnace IX:</strong> Ultra-speed processing</li>
        <li><strong>Enhanced Furnace X:</strong> Almost instantaneous</li>
        <li><strong>Carbonado Edged Furnace:</strong> Smelts items in less than a second</li>
      </ul>
    </div>
    <div class="special-note">
      <strong>Highest Tier:</strong> The Carbonado Edged Furnace which smelts items within less than a second and applies maximum Fortune to smelted items.
    </div>
    <div class="usage-instructions">
      <strong>Progressive Benefits:</strong>
      <ul>
        <li><strong>Speed:</strong> Each tier significantly reduces smelting time</li>
        <li><strong>Fuel Efficiency:</strong> Higher tiers use less fuel per item</li>
        <li><strong>Fortune:</strong> Higher tiers apply Fortune enchantment to smelted items</li>
        <li><strong>Automation:</strong> Advanced tiers work with hoppers and output chests</li>
      </ul>
    </div>
  </div>
</div>
